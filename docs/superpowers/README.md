# Design archive

Point-in-time design records — the specs and plans this project was built from, kept for provenance. They are **historical** and not maintained: some describe earlier decisions that later changed (e.g. early plans reference Anthropic Claude for text generation; the app shipped on Gemini + Groq).

For the current, authoritative architecture and conventions, read [`CLAUDE.md`](../../CLAUDE.md) and [`README.md`](../../README.md) at the repo root.
